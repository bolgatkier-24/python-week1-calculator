# Simple Bill Calculator

This is a small Python program I made for my Week 1 assignment.

## What it does
It asks you for the price of one item and how many you want.  
Then it calculates the total and shows a clear summary.

## How to run it
1. Make sure you have Python installed.
2. Open the file `bill_calculator.py` in any code editor.
3. Run the program.
4. Type the price and quantity when asked.

## Example
Enter the price of one item: $50
Enter the quantity you want: 3
3 items at 50.00 each = 150.00
